# Бизнес-запросы для интернет-магазина

## Запрос 1 --- История заказов покупателя

### Бизнес-вопрос

Какие товары и в каком количестве покупал конкретный клиент?

### Параметры запроса

  |Параметр       |Описание|
  |---------------|--------------------------|
  |`customer_id`  | Идентификатор покупателя|

### Пример результата

  |---------|--------------|---------|-------------|--------|----------|-------|--------------|---- |
  |ID       |Email         |  Номер  |  Дата       |  Товар |   Размер |  Цвет |   Количество | Цена|
  |клиента  |              |   заказа|   создания  |        |          |       |              |     |
  |---------|--------------|---------|-------------|--------|----------|------ |--------------|-----|
  |15       | user@mail.com|   1024  |   2026-10-01|   Nike |    L     |  Black|   2          |  80 |
  |                                                |  Hoodie|          |       |              |  
  
  ----------------------------------------------------------------------------------------------

## Запрос 2 --- Самые продаваемые товары

### Бизнес-вопрос

Какие товары имеют наибольший объём продаж?

### Параметры запроса

  Параметр   Описание
  ---------- -----------------------------------------
  `LIMIT`    Количество выводимых популярных товаров

### Пример результата

  ID товара   Товар             Количество проданных единиц
  ----------- --------------- -----------------------------
  1           Basic T-Shirt                            5420
  2           Winter Jacket                            3120
  3           Sneakers                                 2900

------------------------------------------------------------------------

## Запрос 3 --- Выручка по категориям товаров

### Бизнес-вопрос

Какие категории товаров приносят магазину больше всего дохода?

### Параметры запроса

  Параметр   Описание
  ---------- -----------------------------------------------------
  `status`   Учитываются только завершённые заказы (`completed`)

### Пример результата

  Категория       Выручка
  ------------- ---------
  Shoes            250000
  Clothes          180000
  Accessories       50000

------------------------------------------------------------------------

## Запрос 4 --- Постоянные покупатели

### Бизнес-вопрос

Какие клиенты сделали пять и более заказов?

### Параметры запроса

  Параметр       Описание
  -------------- --------------------------------------
  `min_orders`   Минимальное количество заказов --- 5

### Пример результата

  ID клиента   Email               Количество заказов
  ------------ ----------------- --------------------
  15           user@mail.com                        8
  27           client@mail.com                     12

Используется `HAVING`, так как фильтрация выполняется после группировки.

------------------------------------------------------------------------

## Запрос 5 --- Товары с низким остатком

### Бизнес-вопрос

Какие товары необходимо пополнить на складе?

### Параметры запроса

  Параметр            Описание
  ------------------- ------------------------------------
  `stock_threshold`   Товары с остатком меньше 10 единиц

### Пример результата

  Товар      Размер   Цвет      Остаток
  ---------- -------- ------- ---------
  Sneakers   42       Black           3
  Hoodie     M        White           7
