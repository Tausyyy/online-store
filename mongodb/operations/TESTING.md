# Проверка CRUD и валидации

Автоматизированная демонстрация выполняется командой `npm run crud` после `npm run validate`.

| Проверка                               | Ожидаемый результат                  | Механизм                                  |
| -------------------------------------- | ------------------------------------ | ----------------------------------------- |
| Создать корректный `product_content`   | INSERT успешен                       | JSON Schema + `insertOne`                 |
| Найти карточку по `productId`          | FIND возвращает документ             | `findOne`                                 |
| Обновить название и характеристики     | UPDATE успешен, `updatedAt` меняется | `updateOne`                               |
| Создать отзыв с рейтингом 5            | INSERT успешен                       | Прикладная проверка + JSON Schema         |
| Обновить ожидающий отзыв               | UPDATE успешен                       | Условный `updateOne` по статусу `pending` |
| Создать и удалить ожидающий вопрос     | DELETE удаляет один документ         | `deleteOne` с фильтром по статусу         |
| Вставить карточку без `title`          | Отклонено                            | `required` в JSON Schema                  |
| Создать отзыв с рейтингом 6            | Отклонено                            | Прикладная проверка диапазона             |
| Создать повторный отзыв той же пары ID | Отклонено                            | Уникальный индекс                         |
| Удалить вопрос `answered`              | Отклонено                            | Бизнес-правило в CRUD                     |
| Изменить `productId` карточки          | Отклонено                            | Белый список полей UPDATE                 |

Скрипт печатает каждую проверку в терминал и удаляет тестовые документы в `finally`. Это позволяет
повторять запуск без накопления демонстрационных данных.
