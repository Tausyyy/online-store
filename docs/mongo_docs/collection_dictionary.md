# Словарь коллекций и полей MongoDB

## 1. Коллекция categories

Предназначена для хранения категорий товаров.

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `_id` | UUID | Да | Идентификатор категории |
| `name` | String | Да | Название категории |
| `description` | String | Нет | Описание категории |

Пример документа:

```javascript
{
    _id: UUID("..."),
    name: "Одежда",
    description: "Категория одежды"
}
```

Связь с товарами осуществляется через поле `category_id` коллекции `products`.

Одна категория может содержать несколько товаров (1:N).

## 2. Коллекция products

Предназначена для хранения основной информации о товарах и их характеристик.

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `_id` | UUID | Да | Идентификатор товара |
| `category_id` | UUID | Да | Идентификатор категории |
| `name` | String | Да | Название товара |
| `description` | String | Нет | Описание товара |
| `brand` | String | Нет | Бренд или производитель |
| `attributes` | Object | Да | Характеристики товара |
| `status` | String | Да | Статус публикации |

Пример документа:

```javascript
{
    _id: UUID("..."),
    category_id: UUID("..."),
    name: "Футболка",
    description: "Хлопковая футболка",
    brand: "Example Brand",
    attributes: {
        material: "Хлопок",
        sleeve_length: "Короткий",
        collar_type: "Круглый"
    },
    status: "active"
}
```

### Особенности attributes

Поле `attributes` содержит характеристики, которые могут различаться в зависимости от категории товара.

Примеры:

| Категория | Характеристики |
|---|---|
| Одежда | material, sleeve_length, collar_type |
| Обувь | upper_material, sole_type |
| Аксессуары | material, clasp_type |

Характеристики хранятся непосредственно в документе товара (embedding).

Связь с коллекцией `categories` осуществляется через `category_id`.

## 3. Коллекция skus

Предназначена для хранения вариантов товаров. Каждый документ представляет отдельный вариант с собственными артикулом, размером, цветом, ценой и остатком.

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `_id` | UUID | Да | Идентификатор SKU |
| `product_id` | UUID | Да | Идентификатор товара |
| `sku_code` | String | Да | Артикул варианта |
| `size` | String | Нет | Размер |
| `color` | String | Нет | Цвет |
| `price` | Decimal128 | Да | Актуальная цена |
| `stock` | Int32 | Да | Количество на складе |
| `status` | String | Да | Статус варианта |

Пример документа:

```javascript
{
    _id: UUID("..."),
    product_id: UUID("..."),
    sku_code: "TSHIRT-BLK-M",
    size: "M",
    color: "Черный",
    price: NumberDecimal("1499.00"),
    stock: 25,
    status: "active"
}
```

Артикул `sku_code` должен быть уникальным в пределах коллекции.

Связь с коллекцией `products` осуществляется через `product_id`.

Один товар может иметь несколько вариантов SKU (1:N).

## 4. Связи между коллекциями

| Коллекция | Поле связи | Связанная коллекция | Тип связи |
|---|---|---|---|
| `categories` | `_id` | `products.category_id` | 1:N |
| `products` | `_id` | `skus.product_id` | 1:N |

Характеристики товара хранятся внутри `products.attributes` посредством embedding.

Связи между категориями, товарами и SKU реализуются посредством reference.

## 5. Связь с PostgreSQL

Идентификаторы SKU используются для связи каталога с данными PostgreSQL.

| Таблица PostgreSQL | Поле | Документ MongoDB |
|---|---|---|
| `cart_items` | `sku_id` | `skus._id` |
| `order_items` | `sku_id` | `skus._id` |

В PostgreSQL для `sku_id` используется тип UUID, соответствующий UUID документа MongoDB.

Между этими полями не создаются обычные внешние ключи, поскольку данные находятся в разных СУБД.
